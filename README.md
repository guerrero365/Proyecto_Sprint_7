# 🚗 Dashboard Interactivo: Análisis del Mercado de Vehículos 📈

> *"Acelerando la toma de decisiones con datos precisos y visualizaciones dinámicas."*

Bienvenidos a esta herramienta analítica diseñada para explorar a fondo las tendencias y el comportamiento del mercado automotriz. Esta aplicación web interactiva permite a analistas, estrategas comerciales y entusiastas del sector desglosar precios, evaluar la distribución de modelos y entender qué variables dictan el valor de un vehículo en el mercado actual. 

Mediante un panel de control intuitivo y filtros interactivos, el usuario puede interactuar directamente con la información para extraer *insights* de forma rápida y efectiva.

---

## 🛠️ Tecnologías Utilizadas

El proyecto está construido sobre un stack moderno y eficiente, ideal para el análisis de datos y la creación de aplicaciones web analíticas:

*   **🐍 Python:** El núcleo lógico y analítico para el procesamiento de la información.
*   **🎈 Streamlit:** Framework utilizado para desplegar el frontend de manera ágil, estructurando una interfaz de usuario limpia y completamente responsiva.
*   **📊 Plotly Express:** Motor principal de visualización para renderizar gráficos complejos, altamente estéticos y dinámicos (histogramas, diagramas circulares y gráficos de barras).
*   **🐼 Pandas:** Herramienta fundamental para la limpieza, manipulación y estructuración de las bases de datos.
